# Providers and Node Clusters

Define providers and node clusters and how they relate to datacenters and capacity.

## Cover
- Provider definition, credentials, health
- Node clusters under a provider; mapping to real infrastructure
- Datacenter linkage: one datacenter per node cluster
- Capacity aggregation and sync lifecycle
- Provider types and capabilities matrix (libvirt, Proxmox, Kubernetes-like)
